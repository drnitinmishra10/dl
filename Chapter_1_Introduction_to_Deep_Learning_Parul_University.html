1. Introduction to Artificial Intelligence

1.1 What is Artificial Intelligence?

Artificial Intelligence (AI) is a branch of computer science concerned with developing computer systems that perform tasks normally associated with human intelligence. These tasks include learning, reasoning, recognizing patterns, understanding language, solving problems and supporting decisions.

Student-friendly definition: Artificial Intelligence is the ability of a computer system to perform intelligent tasks such as learning, reasoning, recognition and decision-making.

Conceptual clarification: These areas are not all arranged in one strict hierarchy. Machine Learning is a major approach within AI, while NLP and computer vision are application fields that can use multiple AI techniques.

Lecture 1 classroom example

A hospital wants a system that identifies patterns in chest X-ray images that may be associated with pneumonia. A rule-based program relies on rules written by people. A learning-based system can instead learn statistical patterns from labelled examples and use them to make predictions.

Ask the class: Can a computer recognize a disease from an image without a human writing a separate rule for every possible image pattern? What information would the computer need?

2.4 Types of Machine Learning

A. Supervised learning

The model learns from labelled examples: each training input has a corresponding target or label.

AgeGlucoseRecorded label

Common algorithms: Linear Regression, Logistic Regression, Decision Tree, Random Forest, Support Vector Machine and K-Nearest Neighbors.

B. Unsupervised learning

The model searches for patterns or groups in data without predefined target labels. Example: grouping patient records by similarity.

Common algorithms: K-Means, Hierarchical Clustering and Principal Component Analysis.

C. Reinforcement learning

An agent interacts with an environment and learns a policy using rewards or penalties. Research examples include robotic control and resource optimization. The objective is to maximize cumulative reward.

3. Deep Learning

3.1 Definition

Deep Learning is a specialized subfield of Machine Learning that uses artificial neural networks with multiple processing layers to learn complex patterns and representations from data.

3.2 Why is it called “deep”?

The term deep refers to multiple processing layers between input and output. A network with several hidden layers can learn progressively more complex representations.

Input data
→
Early layers
simple patterns
→
Middle layers
textures / shapes
→

In image recognition, early layers may respond to edges and simple patterns; intermediate layers may respond to textures and shapes; deeper layers may represent object parts or class-related patterns. The exact representations depend on the data, architecture and training.

Remember: AI is the broad field; ML is an approach within AI; DL is an approach within ML.

3.4 Characteristics of Deep Learning

  • Uses artificial neural networks.
  • Can contain multiple hidden layers.
  • Learns complex patterns from data.
  • Can automatically learn useful features or representations.
  • Supports image, audio, video and text processing.
  • Often requires substantial computational resources; GPUs can accelerate training.
  • May benefit from large datasets, while transfer learning can reduce data requirements in some tasks.
  • Can model highly nonlinear relationships.
  • Requires careful evaluation to detect overfitting and biased predictions.

4. Importance of Deep Learning in Public Health

4.1 What is Public Health?

Public Health is the science and practice of protecting and improving the health of populations through prevention, health promotion, disease surveillance, healthcare planning and evidence-based interventions.

4.2 Why use Deep Learning in healthcare?

Healthcare generates many kinds of data: X-rays, MRI and CT scans, electronic health records, laboratory reports, ECG signals, patient-monitoring data, genomic information and clinical text. Deep Learning can help analyze complex patterns in these data types at scale.

4.3 Major application areas

A. Early disease detection support

Models can identify image patterns associated with conditions such as pneumonia, diabetic retinopathy and skin lesions. Outputs require clinical validation.

B. Disease-risk prediction

Models can estimate risk from patient information, for example cardiovascular risk, diabetes risk or hospital readmission risk.

C. Medical image analysis

Applications include tumour segmentation, lung-image analysis, brain MRI analysis and retinal-image classification.

D. Health monitoring

Sequential measurements can be analyzed for heart-rate trends, ECG patterns, sleep and respiratory monitoring.

E. Public-health surveillance

Models can support disease-trend analysis, outbreak surveillance and healthcare-resource planning.

F. Clinical text analysis

Language models and other NLP systems can help classify, summarize or extract information from clinical documents, subject to privacy and safety controls.

4.5 Benefits

  • Processes large volumes of medical data.
  • Learns complex patterns from images and signals.
  • Can support repetitive analysis tasks.
  • May help identify abnormalities for further review.
  • Supports healthcare research and personalized-care investigations.
  • Can assist, but should not replace, professional judgement.

4.6 Limitations and responsible use

  • Data quality and labelling problems.
  • Insufficient or unrepresentative datasets.
  • Dataset bias and unequal performance across populations.
  • High computational requirements.
  • Limited interpretability in some models.
  • Privacy and confidentiality concerns.
  • Poor generalization to other hospitals or populations.
  • False-positive and false-negative predictions.
Professor's emphasis: Present Deep Learning as a decision-support technology, not an automatic replacement for doctors. Clinical use requires appropriate validation, human oversight, privacy safeguards and regulatory compliance.

5. Difference between Machine Learning and Deep Learning

5.1 Conceptual difference

In many traditional ML workflows, people select or engineer useful features before applying a learning algorithm. Deep Learning uses multilayer neural networks that can learn hierarchical representations directly from raw or minimally processed data.

5.2 Healthcare example: pneumonia image classification

Traditional ML workflow

  1. Collect chest X-rays.
  2. Design or extract features such as texture and intensity.
  3. Supply features to an algorithm such as SVM.
  4. Classify the extracted features.

Deep Learning workflow

  1. Collect labelled X-ray images.
  2. Resize and normalize images.
  3. Train a CNN to learn representations.
  4. Generate predictions.
  5. Evaluate with suitable metrics.

5.3 Feature engineering versus representation learning

Feature engineering: A human expert decides which characteristics should be extracted from data.

Representation learning: A neural network learns useful characteristics from data during training. In a CNN, convolutional layers learn filters that respond to useful patterns.

5.4 When should each be used?

Consider traditional ML when

  • Data is structured and tabular.
  • The dataset is relatively small.
  • Interpretability is important.
  • Computational resources are limited.
  • A simpler model performs adequately.

Consider Deep Learning when

  • Data includes complex images, audio or text.
  • Complex representations are needed.
  • Sufficient data and compute are available.
  • It offers a measurable advantage over baselines.
Key lesson: Deep Learning is not automatically superior to traditional ML. Choose a model based on the problem, data, performance, interpretability and computational cost.

6. Biological neuron and artificial neuron

6.1 Biological inspiration

The human brain contains billions of neurons that communicate through electrochemical signals. A biological neuron has dendrites, a cell body (soma), an axon and synapses.

PartFunction
DendritesReceive incoming signals.
SomaIntegrates incoming signals.
AxonCarries signals away from the cell body.
SynapsesEnable communication with other neurons.

6.2 Artificial neuron

An artificial neuron is a mathematical computational unit. It receives inputs, multiplies them by weights, adds a bias and applies an activation function. It is a simplified computational analogy, not an exact copy of a biological neuron.

Input x₁
Weight w₁
↘
Weighted sum
Σ(wᵢxᵢ) + b
→
Activation
f(z)
→
Output y
Input x₂
Weight w₂
↗
Bias b

6.3 Mathematical representation

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b
y = f(z)
  • x: input values or features.
  • w: weights that determine each input's contribution.
  • b: bias, an additional learnable parameter.
  • f: activation function.
  • y: neuron output.

6.4 Worked numerical example

Suppose three illustrative input scores are x₁ = 0.8, x₂ = 0.9 and x₃ = 0.6. Let weights be w₁ = 0.3, w₂ = 0.5 and w₃ = 0.2, with bias b = 0.1.

z = (0.3 × 0.8) + (0.5 × 0.9) + (0.2 × 0.6) + 0.1
z = 0.24 + 0.45 + 0.12 + 0.1 = 0.91

Using sigmoid, f(z) = 1 / (1 + e−z), so f(0.91) ≈ 0.713.

This is an illustrative neuron output, not a clinically calibrated probability of disease.

6.5 Understanding weights and bias

Weights determine how strongly each input contributes to the weighted sum. Bias shifts the activation threshold and gives the neuron additional flexibility. Without bias, a linear decision boundary is constrained to pass through the origin.

6.6 Activation function

An activation function transforms the weighted sum into the neuron's output. Common examples include Sigmoid, ReLU, Tanh and Softmax. Their mathematical properties and use cases are studied in detail in Chapter 2.

7. Neural networks: structure and working

7.1 What is an Artificial Neural Network?

An Artificial Neural Network (ANN) is a computational model made of interconnected artificial neurons arranged in layers. During training, the model learns by adjusting weights and biases.

7.2 Main components

  • Input layer
  • One or more hidden layers
  • Output layer
  • Weights and biases
  • Activation functions

7.3 Neural network architecture

Illustrative architecture: 3 inputs, 3 neurons in the first hidden layer, 2 in the second hidden layer and 1 output.

7.4 Input layer

The input layer receives the features. For a tabular diabetes-risk example, inputs might include age, BMI, glucose and blood pressure. Four input features would be represented by four input units.

7.5 Hidden layers

Hidden layers process information from previous layers. Each neuron computes a weighted sum, adds bias, applies an activation function and passes the result forward. Multiple hidden layers can learn complex relationships.

7.6 Output layer

The output layer produces the model's result. Examples: one sigmoid output for binary classification; multiple softmax outputs for multiclass classification; or a numerical output, often linear, for regression.

7.7 How does a neural network work?

Stage 1: Forward propagation

  1. Input data is supplied.
  2. Each neuron calculates a weighted sum.
  3. Bias is added.
  4. Activation functions are applied.
  5. Results move to the next layer.
  6. The output layer generates a prediction.

Stage 2: Learning during training

The prediction is compared with the target using a loss function. A training algorithm calculates gradients and updates weights and biases to reduce loss.

Training data
→
Neural network
→
Prediction
→

↓

7.8 Example: ANN for binary classification

Suppose a model receives four patient-record features: age, BMI, glucose and blood pressure. An illustrative architecture could have four input units, eight neurons in hidden layer 1, four neurons in hidden layer 2 and one sigmoid output. The output can be converted to a class using a selected threshold. The model's output is not a diagnosis unless clinically validated.

8. Introduction to Deep Learning network types

NetworkTypical dataExample application
Feedforward Neural NetworkTabular / fixed-size inputsDiabetes-risk classification
Convolutional Neural Network (CNN)Images and spatial dataMedical image classification
Recurrent Neural Network (RNN)Sequential dataTime-series or ECG analysis

Feedforward Neural Network

Information moves from input to output without recurrent connections. Common uses include tabular classification and regression.

Convolutional Neural Network (CNN)

CNNs learn spatial patterns in data, especially images. Applications include medical image classification, object recognition and image segmentation. CNN architecture is covered in Chapter 4.

Recurrent Neural Network (RNN)

RNNs process sequential information. Recurrent connections allow information from earlier time steps to influence processing at later time steps. Applications include time-series analysis and sequential text processing. RNN and LSTM are covered in Chapter 5.

9. Python demonstrations

These demonstrations use NumPy and Matplotlib to make the mathematics visible. The Keras example is an optional preview of Chapter 3. Run the programs in Jupyter Notebook or Google Colab.

Practical 1: Artificial neuron using NumPy

Objective: Calculate a neuron's output using inputs, weights, bias and sigmoid activation.

import numpy as np

# Input values
inputs = np.array([0.8, 0.9, 0.6])

# Weights
weights = np.array([0.3, 0.5, 0.2])

# Bias
bias = 0.1

# Weighted sum
z = np.dot(inputs, weights) + bias

# Sigmoid activation
output = 1 / (1 + np.exp(-z))

print("Weighted Sum:", z)
print("Neuron Output:", output)

Expected output:

Weighted Sum: 0.91
Neuron Output: 0.713
Line-by-line teaching explanation
  1. import numpy as np imports NumPy for numerical operations.
  2. The input array contains three values supplied to the neuron.
  3. The weights array contains one weight for each input.
  4. np.dot(inputs, weights) computes the sum of input-weight products.
  5. Bias is added to the weighted sum.
  6. The sigmoid formula transforms the result to a value between zero and one.

This program demonstrates a single neuron's forward computation. It does not train the neuron.

Practical 2: Visualizing the sigmoid function

Objective: Observe how sigmoid transforms different input values.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-10, 10, 100)
sigmoid = 1 / (1 + np.exp(-x))

plt.plot(x, sigmoid)
plt.xlabel("Input")
plt.ylabel("Sigmoid Output")
plt.title("Sigmoid Activation Function")
plt.grid()
plt.show()

Expected observations: The output approaches zero for large negative inputs, approaches one for large positive inputs, equals 0.5 at x = 0 and remains between zero and one.

Ask students: Why might sigmoid be useful as the output activation for a binary classification model?

Practical 3: A simple multilayer network using NumPy

Objective: Demonstrate how information moves from an input layer through a hidden layer to an output layer.

import numpy as np

# Input values
X = np.array([0.5, 0.8])

# Weights from input to hidden layer
W1 = np.array([
    [0.2, 0.4],
    [0.3, 0.5]
])

# Hidden-layer bias
b1 = np.array([0.1, 0.1])

# Hidden-layer computation
z1 = np.dot(X, W1) + b1

# ReLU activation
h = np.maximum(0, z1)

# Weights from hidden to output
W2 = np.array([
    [0.6],
    [0.7]
])

# Output bias
b2 = np.array([0.1])

# Output computation
z2 = np.dot(h, W2) + b2

print("Input:", X)
print("Hidden Layer:", h)
print("Output:", z2)

This example contains two input features, two hidden neurons and one output neuron. It uses fixed weights and does not perform training.

D. Numerical questions

Question 1. An artificial neuron has x₁ = 0.6, x₂ = 0.8; w₁ = 0.4, w₂ = 0.5; and bias = 0.2. Calculate the weighted sum.

Solution: z = (0.6 × 0.4) + (0.8 × 0.5) + 0.2 = 0.24 + 0.40 + 0.20 = 0.84.

Question 2. Calculate sigmoid output for z = 0.

Solution: sigmoid(0) = 1 / (1 + e⁰) = 1 / 2 = 0.5.
