3. Machine Learning vs Deep Learning

3.1 Machine Learning

Machine Learning (ML) is a field within Artificial Intelligence in which algorithms learn patterns from data to make predictions or decisions, rather than relying only on explicitly written rules for every case.

3.2 Deep Learning

Deep Learning (DL) is a specialized area of ML that uses neural networks with multiple processing layers to learn increasingly useful representations from data.

3.3 Core differences

3.4 Feature engineering vs representation learning

Traditional ML

A domain expert often identifies or constructs relevant input features before model training. Example: extracting texture descriptors from an X-ray before using an SVM.

Deep Learning

Multiple network layers can learn useful features during training. Example: a CNN learns image filters and higher-level representations from training images.

Teaching example: For classifying cats and dogs, a traditional workflow may use hand-designed image features. A CNN can learn edges, textures, shapes and object-related representations from labelled examples.

3.5 When to choose which?

  • Prefer trying traditional ML for smaller structured datasets, limited compute or when interpretability is a priority.
  • Consider DL for complex high-dimensional data such as images, audio and text, provided data and computational resources are suitable.
  • Always compare against a sensible baseline. Deep Learning is not automatically the best solution.

4.1 Supervised learning

The model learns from labelled examples. Each training example contains input features and a known target label or value.

5. Neural network basics

An Artificial Neural Network (ANN) is a computational model made of connected processing units called artificial neurons. A network typically contains an input layer, one or more hidden layers and an output layer.

5.1 Artificial neuron: mathematical model

A neuron multiplies each input by a corresponding weight, adds the bias and applies an activation function.

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b
a = f(z)
  • xᵢ: input feature
  • wᵢ: weight associated with the input
  • b: bias parameter
  • z: weighted sum before activation
  • f: activation function
  • a: neuron activation/output

5.2 Numerical example

Let x₁ = 0.6, x₂ = 0.8, w₁ = 0.4, w₂ = 0.5 and b = 0.2.

z = (0.6 × 0.4) + (0.8 × 0.5) + 0.2 = 0.84

The weighted sum is 0.84. The activation function then transforms this value into the neuron's output.

5.3 Why are weights and bias needed?

Weights control the contribution of inputs. Bias shifts the activation threshold and provides additional flexibility. During training, the learning algorithm adjusts these parameters to reduce prediction error.

6. Perceptron

6.1 Definition

The perceptron is one of the simplest artificial neural models, commonly used to introduce binary classification. It computes a weighted sum of inputs and applies a threshold (step) activation function.

Inputs
x₁, x₂, …, xₙ
→
Weighted sum
Σwᵢxᵢ + b
→
Step function
→
Class 0 / 1

6.2 Perceptron equations

z = Σᵢ wᵢxᵢ + b
ŷ = 1 if z ≥ 0; otherwise ŷ = 0

6.3 Worked example

Inputs x₁ = 1 and x₂ = 0; weights w₁ = 0.7 and w₂ = −0.4; bias b = −0.2.

z = (1 × 0.7) + (0 × −0.4) − 0.2 = 0.5

Since z ≥ 0, the perceptron predicts class 1.

6.4 Perceptron learning idea

For a misclassified training example, the perceptron updates its weights in the direction that reduces the classification error. One common form is:

wᵢ(new) = wᵢ(old) + η(y − ŷ)xᵢ
b(new) = b(old) + η(y − ŷ)

Here η is the learning rate, y is the actual label and ŷ is the predicted label. The classical perceptron converges for linearly separable training data; it cannot solve non-linearly separable problems such as XOR with a single layer.

7. Activation functions: Sigmoid, ReLU and Softmax

Activation functions introduce non-linearity into neural networks. Without suitable nonlinear activations, stacking linear transformations would still produce an overall linear transformation.

7.1 Sigmoid

σ(z) = 1 / (1 + e−z)
  • Output range: 0 to 1 (exclusive for finite inputs).
  • Often used in the output layer of binary classification models.
  • Can saturate for very large positive or negative inputs, producing small gradients.

7.2 ReLU (Rectified Linear Unit)

ReLU(z) = max(0, z)
  • Negative input produces zero.
  • Positive input is unchanged.
  • Computationally simple and widely used in hidden layers.
  • Some neurons can become inactive for all inputs, a phenomenon often called the dying ReLU problem.

7.3 Softmax

Softmax(zᵢ) = ezᵢ / Σⱼ ezⱼ
  • Converts a vector of logits into values between zero and one.
  • Outputs sum to one.
  • Commonly used for mutually exclusive multiclass classification.

Example: For logits [2, 1, 0], softmax is approximately [0.665, 0.245, 0.090]. The largest score corresponds to the first class.

Softmax outputs are normalized model scores. They should not automatically be interpreted as well-calibrated real-world probabilities.

8. Gradient Descent

8.1 What is optimization?

Training a neural network involves choosing weights and biases that make predictions fit the training targets. A loss function measures the model's error. Optimization algorithms adjust model parameters to reduce this loss.

8.2 Gradient descent

Gradient descent is an iterative optimization method. It updates parameters in the direction opposite to the gradient of the loss function.

w(new) = w(old) − η × ∂L/∂w
  • w: model parameter (weight)
  • η: learning rate
  • L: loss function
  • ∂L/∂w: gradient of loss with respect to the weight

8.3 Intuitive explanation

Imagine standing on a hill in fog and trying to reach the lowest point. You check the slope where you are standing and take a step downhill. Repeating this process can move you towards a minimum.

8.4 Numerical illustration

Suppose L(w) = w². Its derivative is dL/dw = 2w. Start with w = 4 and learning rate η = 0.1.

w(new) = 4 − 0.1(2 × 4) = 3.2

Next update: w = 3.2 − 0.1(6.4) = 2.56. Repeated updates move w towards zero, the minimum of this simple function.

8.5 Learning-rate effect

  • Too small: learning may be very slow.
  • Too large: updates may overshoot or fail to converge.
  • Suitable learning rate: makes stable progress toward a low-loss region.

8.6 Common gradient descent variants

  • Batch Gradient Descent: computes the gradient using the full training dataset.
  • Stochastic Gradient Descent (SGD): updates using one training example at a time.
  • Mini-batch Gradient Descent: updates using a small batch; widely used in deep learning.

9. Backpropagation

9.1 Definition

Backpropagation is an algorithm for efficiently calculating gradients of a neural network's loss with respect to its weights and biases. It applies the chain rule of calculus, propagating error derivatives backward from the output layers toward earlier layers.

9.2 Training cycle

Input data
→
Forward pass
→
Prediction
→
Loss
↓
Backward pass
→
Gradients
→
Update weights

9.3 Steps in backpropagation

  1. Initialize weights and biases.
  2. Perform forward propagation to calculate the prediction.
  3. Calculate loss by comparing prediction with the target.
  4. Compute gradients of the loss with respect to output-layer parameters.
  5. Use the chain rule to propagate gradients backward through earlier layers.
  6. Update weights and biases using an optimizer such as gradient descent.
  7. Repeat for batches and epochs until training stops.

9.4 Chain rule intuition

If a parameter affects a hidden activation, which affects the output, which affects the loss, the chain rule multiplies the local derivatives along that path.

∂L/∂w = (∂L/∂a) × (∂a/∂z) × (∂z/∂w)

This expression is a simplified single-neuron chain. In a multilayer network, gradients are accumulated across connected paths.

9.5 Difference between forward propagation and backpropagation

Forward propagationBackpropagation
Moves input information toward the output.Moves gradient information from output toward earlier layers.
Computes activations and prediction.Computes derivatives of loss with respect to parameters.
Uses current weights and biases.Uses the chain rule and stored intermediate values.
Produces the prediction and loss (after target comparison).Provides gradients for parameter updates.
Important distinction: Backpropagation calculates gradients; an optimizer such as gradient descent uses those gradients to update parameters. They are related but not the same operation.

10. Deep Learning frameworks: TensorFlow and Keras

10.1 What is a Deep Learning framework?

A Deep Learning framework provides software tools for building, training, evaluating and deploying neural networks. It handles operations such as tensor computation, automatic differentiation, GPU execution and model management.

TensorFlow

An open-source platform for numerical computation and machine learning. It provides tensor operations, automatic differentiation, model training and deployment tools.

Official TensorFlow website

Keras

A high-level deep learning API designed to make model development readable and accessible. Keras can use TensorFlow as a backend through the commonly used TensorFlow Keras interface.

Official Keras website

10.2 TensorFlow and Keras relationship

TensorFlow provides lower-level computational capabilities and a broad ecosystem. Keras provides a higher-level interface for defining and training models. In this course, students can use tf.keras to build introductory models.

10.4 Minimal Keras example

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# A simple model for four numerical input features
model = keras.Sequential([
    keras.Input(shape=(4,)),
    layers.Dense(8, activation="relu"),
    layers.Dense(4, activation="relu"),
    layers.Dense(1, activation="sigmoid")
])

model.summary()

This code defines an architecture; it does not train the model. A training dataset, loss function, optimizer and call to fit() are required for training.

11. Anaconda environment setup

11.1 What is Anaconda?

Anaconda is a Python distribution and environment-management platform commonly used in data science and machine learning. It helps manage Python versions, packages and isolated project environments. Anaconda Navigator provides a graphical interface; Conda commands can be used from a terminal.

11.2 Why use a separate environment?

  • Isolates packages for each project.
  • Reduces dependency conflicts.
  • Makes experiments easier to reproduce.
  • Allows different projects to use different package versions.

11.3 Suggested setup using Conda

# Create a new environment
conda create -n deep-learning python=3.11

# Activate the environment

12. Python practical demonstrations

These exercises reinforce the syllabus concepts. They can be run in Jupyter Notebook or Google Colab. The first three use NumPy; the last is a framework preview.

Practical 1: Perceptron forward calculation

Objective: Calculate a weighted sum and apply a step function.

import numpy as np

x = np.array([1, 0])
w = np.array([0.7, -0.4])
b = -0.2

z = np.dot(x, w) + b
prediction = 1 if z >= 0 else 0

print("Weighted sum:", z)
print("Predicted class:", prediction)

Expected output: Weighted sum = 0.5; predicted class = 1.

Practical 2: Compare activation functions

import numpy as np

z = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])

sigmoid = 1 / (1 + np.exp(-z))
relu = np.maximum(0, z)

logits = np.array([2.0, 1.0, 0.0])
exp_logits = np.exp(logits - np.max(logits))
softmax = exp_logits / np.sum(exp_logits)

print("Input:", z)
print("Sigmoid:", sigmoid)
print("ReLU:", relu)
print("Softmax for [2,1,0]:", softmax)
print("Softmax sum:", np.sum(softmax))

Students should observe that sigmoid values lie between zero and one, ReLU clips negative values to zero, and softmax outputs sum to one.

Practical 3: Gradient descent for L(w) = w²

learning_rate = 0.1
w = 4.0

for step in range(10):
    gradient = 2 * w       # derivative of w squared
    w = w - learning_rate * gradient
    print(step + 1, round(w, 5))

The parameter moves closer to zero, the minimum of this simple loss function.

Practical 4: Visualize sigmoid and ReLU

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-6, 6, 200)
sigmoid = 1 / (1 + np.exp(-x))
relu = np.maximum(0, x)

plt.plot(x, sigmoid, label="Sigmoid")
plt.plot(x, relu, label="ReLU")
plt.xlabel("Input")
plt.ylabel("Output")
plt.title("Activation functions")

D. Numerical problems

Problem 1: Perceptron weighted sum

x₁ = 0.5, x₂ = 0.8; w₁ = 0.4, w₂ = 0.3; b = −0.1. Calculate z.

Solution: z = (0.5 × 0.4) + (0.8 × 0.3) − 0.1 = 0.20 + 0.24 − 0.10 = 0.34.

Problem 2: Sigmoid

Find sigmoid(0).

Solution: 1/(1 + e⁰) = 1/2 = 0.5.

Problem 3: One gradient descent update

Let L(w) = w², w = 3 and η = 0.1. Find the next value of w.

Solution: dL/dw = 2w = 6. Therefore w(new) = 3 − (0.1 × 6) = 2.4.
